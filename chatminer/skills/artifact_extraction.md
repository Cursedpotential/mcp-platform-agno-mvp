# Skill: Artifact Extraction

## Purpose
Find code blocks, documents, files, and references embedded in conversations.

## When to Use
- After parsing — find what was created/discussed in the chat
- Building an evidence inventory
- Finding code snippets to reuse
- Identifying legal documents created by AI

## What Gets Extracted

### Code Snippets (ArtifactType.CODE_SNIPPET)
```python
from chatminer.core.artifacts import extract_artifacts

artifacts = extract_artifacts(messages)
code_snippets = [a for a in artifacts if a.artifact_type.value == "code_snippet"]
```

**Look for:**
- Fenced code blocks (```python ... ```)
- Inline code that is substantial (>10 chars)
- Configuration files (JSON, YAML, SQL)

### Documents Created In-Chat (ArtifactType.DOCUMENT)
- .docx files generated by AI assistants
- Reports, analyses, handoff documents
- Strategy documents

**Example from your data:**
- `Evidence Processor v4 Code Hand-off.docx` — Created by AI during development chat
- `notes - analysis module ..docx` — Created by AI during analysis chat

### File References (ArtifactType.DATA_FILE)
- Files mentioned or attached in conversation
- Evidence files referenced (texts, emails, photos)
- Data exports (JSON, CSV)

### URLs (ArtifactType.URL)
- External links shared in conversation
- Source citations (especially from Perplexity)
- Documentation links

### Legal Strategies (ArtifactType.STRATEGY_DOC)
- Legal theories discussed
- Case strategies
- Argument frameworks

## How to Use
```python
from chatminer.core.artifacts import extract_artifacts

artifacts = extract_artifacts(messages)
for art in artifacts:
    print(f"{art.artifact_type.value}: {art.title}")
    if art.content:
        print(f"  Content: {art.content[:100]}...")
```

Or via CLI:
```bash
python -m chatminer artifacts parsed.json -o artifacts.json
```

## Deduplication
Artifacts are automatically deduplicated by (type, title, content[:100]).
If the same code block appears in multiple messages, only one artifact is kept.
