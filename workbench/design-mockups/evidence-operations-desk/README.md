# Evidence Operations Desk Mockup

> _Byline: Codex · GPT-5 · 2026-08-15_

This standalone mockup explores a desktop-first daily operations surface for
reviewing provenance-bound evidence drafts. Open `index.html` directly; it has
no build step, external assets, network calls, or production integration.

## Direction

- A graphite navigation chassis surrounds a warm-paper evidence workspace.
- Dense tabular rhythm favors long operator sessions over dashboard spectacle.
- The right inspector is a continuous custody jacket: canonical source →
  normalized record → evidence draft → human gates → court-safe status.
- Canonical evidence, Knowledge results, Graphiti belief memory, and generated
  work product receive distinct labels and visual treatments.
- Amber means human attention, muted green means verified, and red is reserved
  for actual custody or legal-safety failures.
- The Matter/CourtCase header preserves the text Knowledge partition distinction
  rather than presenting `primary` as a court identifier.

## Interaction and responsive tradeoffs

Evidence rows update the inspector, tabs filter queue states, and search filters
visible records. At narrower desktop/tablet widths the navigation compresses to
an icon rail; below 900px the inspector follows the evidence table so the full
provenance chain remains readable. The mockup intentionally prioritizes the
1440px evidence-desk workflow and does not attempt to simulate every empty,
loading, or error state of the production application.
