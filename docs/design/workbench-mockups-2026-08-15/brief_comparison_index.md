# Workbench Mockups — Review Index Brief

> _Byline: Codex · GPT-5 · 2026-08-15_

## Objective

Create a compact self-contained HTML landing page that lets the owner quickly
compare and open the three Workbench mockups after work.

## Content

- Evidence Operations Desk: dense forensic operations and custody provenance.
- Temporal Case Atlas: as-lived/hindsight/delta exploration.
- Modular Service Cockpit: configurable service workspaces and context spine.
- For each: a concise strength, cost/tradeoff, best-fit workflow, and direct
  relative link to its `index.html`.
- Include a small comparison matrix covering evidence review, horizon analysis,
  platform operations, density, customizability, and implementation complexity.
- Link the three evaluation reports using repository-relative paths where an
  HTML browser can reach them; label them as review notes rather than app pages.

## Direction

Neutral editorial review board that does not visually favor one variant.
Lightweight, high-contrast, keyboard accessible, responsive, and honest about
the fact that these are prototypes.

## Constraints

- Output `workbench/design-mockups/index.html` and `README.md`.
- Self-contained; no network requests or external assets.
- Preserve all three variant directories.
- No production application edits.
