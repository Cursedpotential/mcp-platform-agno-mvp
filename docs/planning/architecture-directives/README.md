# .planning/ — Working Plans

> This directory holds active working plans (not historical history — that lives
> in `docs/planning/`).

## Convention

- Active plans go here as `<topic>.md`.
- Completed plans move to `docs/planning/` for archival.
- The `plans/` directory (repo root) is the long-term home for active plans;
> this `.planning/` directory is for scratch/temporary planning state.

> Currently empty. When a plan is active, add a `.md` file here.
