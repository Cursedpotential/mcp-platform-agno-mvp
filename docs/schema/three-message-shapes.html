How data moves, end to end target after rulings

Five lanes top to bottom: intake and custody, parse to immutable raw, derive the spine and its projections, analyze under a knowledge horizon, conclude for court. Solid boxes exist today; the blue ones are where shape changes. Under D-069 the raw landing zone is context, not evidence: ingest hashes are fingerprints; custody (H1 re-verify → H2/H3 → evidence.*) begins only when you promote.

Immutableevidence.* — custody + PROMOTED records only (D-069). raw, rejected, ingest_run move to the context layer (owner 03:10); only the promotion path writes here.
Re-derivableworking.* — rebuilt from raw at any time. Wipe + re-derive is the fix path, never edit.
HorizonThe walk sees a record only when source_available_from ≤ horizon_at. Vector search applies the same filter before top-k.
