# Documentation archive

> _Byline: Codex · GPT-5 · 2026-08-18._

This tree preserves completed, superseded, historical, experimental, and design-only
documentation without deleting it. Categories are organized by lifecycle, not authority:

- `handoffs/` — completed or superseded dated lane handoffs.
- `inventories/` — point-in-time repository/deployment inventories.
- `plans/` — dated plans, proposals, blueprints, and experimental packages.
- `summaries/` — compact session summaries.
- `evaluations/` — dated evaluations and patch reports.
- `design-history/` — reserved for mockup/design history kept separate from production truth.

ADRs and the append-only `DECISION_LOG.md` remain in place. Archive documents are context,
not current implementation or deployment proof. When a task is completed or superseded,
remove it from the active TODO/current handoff and move it here in the same completion change.
Never delete archive material; the owner alone may remove anything from a deletion quarantine.
