Do not commit this tree as-is

The rename sweep is a naive string replace. It breaks the Go build and corrupts English prose.

Verified by running the compiler:

cd engine && go build ./... # github.com/Cursedpotential/mcp-platform-agno-mvp/engine/parser parser\registry.go:31:13: undefined: reference

The sweep replaced the Go identifier registry with reference at its usage sites while leaving the declarations as registry. In engine/chunk/registry_test.go the variable is declared on lines 37, 52, 79, 103 and 139 as registry, err := NewRegistry(...) and then called as reference.Select(...). That is undefined-variable and declared-and-not-used — two hard compile errors.

20 identifier breaks across 5 files: chunk/registry.go (1), chunk/registry_test.go (10), parser/parser_test.go (6), parser/registry.go (1), stagegraph/graph_test.go (2). Go stops at the first failing package, so only one error surfaces today; the rest appear as each is fixed.

It also replaced the ordinary English word reference with registry in prose and comments across 16 files, producing text like “cross-registry”, “a doc-only registry”, “the caller-minted registry”, “use the integration page as the main detailed registry”.

Not everything is damaged: engine/postgres/uiw_schema_probe.go's 20 changes are inside SQL string literals and are correct. The Python/SQL-qualified renames sampled earlier are correct. The breakage is confined to Go identifiers and to prose.
