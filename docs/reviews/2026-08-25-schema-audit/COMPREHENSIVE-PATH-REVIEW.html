Plain English: what changed

Old: custody starts during intake

A file can enter evidence/custody before it is parsed and before the owner selects it.

→

New: context first

Everything lands as context. Only the governed R04 promotion command begins custody after independent H1/H2/H3 verification.

Old: agents can obtain generic database writes

The orchestration framework can bypass approvals, receipts and domain rules.

→

New: typed commands only

Agno is a replaceable runner. Least-privilege roles permit only governed platform commands.

Old: external stores can drift quietly

Local acknowledgements and direct access do not prove complete, authorized projection state.

→

New: R09 reconciliation

Immutable PG manifests compare membership, counts, hashes and versions before Surreal is admitted.

Old: the product delta is not implemented

The walk scaffold does not run a paired as-lived/hindsight experience or preserve canonical beliefs.

→

New: Surreal executes, PG proves

Surreal performs the temporal analysis; PG keeps lifecycle, retrieval, belief, checkpoint, pair, delta and legal-review ledgers.

Old: chat export can reach evidence import

The current Workbench promotion route violates the permanent context-only boundary.

→

New: chat produces investigation work

Typed claims, events, concerns, observations, strategies and created works retain chat lineage but carry zero evidentiary weight.

Old: timeline is fragmented tables and views

There is no maintained timeline product, immutable export generation or reconciled edit loop.

→

New: maintained Timesketch fork

The fork shows context candidates and evidence-approved entries, backed by immutable PG projection generations.

Old: edits can become store-local state

Tags, annotations or bulk changes can drift from canonical context and authority.

→

New: governed round trip

Every edit returns to PG as a version-bound context command. Changes to approved entries become amendment candidates for re-review and governed successors.

Resolved rulings and remaining choices

CR-001 · AI-chat authority · resolved D-082/D-083

Owner ruling: AI chat is permanently context-only and never evidence. Extraction fans out into claim/event candidates, investigation leads and evidence needs, AI observations, strategies, and immutable created works. Claims enter the claim chart and trigger an independent evidence search; chat lineage has zero evidentiary weight.

CR-001A · Timesketch fork and editing · resolved D-084/D-085

Owner ruling: maintain a real Timesketch fork that displays context candidates and evidence-approved timeline entries. Individual and bulk edits return through version-bound PostgreSQL context commands. Any change to an approved entry becomes a context amendment candidate; the approved version remains unchanged until governed re-review and reconciliation create a successor.

CR-002 · Realization targets

Proposal: allow exact record-version, source-span, claim and established-fact targets through separate typed relations. Require at least one target at commit.

CR-003 · Durable delta

Proposal: Surreal computes the pair; PG versions the result. Analytical items may be unanchored, but court-eligible items require an established fact and exact custody-backed citation.

CR-004 · Identity resolution history

Proposal: preserve verbatim participants forever and use append-only resolution assertions before resolved identity influences facts or legal output.

CR-005 · Later physical contracts

Proposal: finish the R09–R14 manifest, projection, walk, legal and cutover ledgers before implementation begins from the unified physical model.

CR-006 · Capacity and retention

Proposal: benchmark representative data, then freeze partitioning, pgvector indexing, batch size, projection lag, retention, soak and rollback thresholds. Do not guess them.
