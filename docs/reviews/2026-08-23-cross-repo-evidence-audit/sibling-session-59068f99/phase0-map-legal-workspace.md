## 0. Framing fact, verified in code, not in docs

`api/legal_workspace/api/main.py:152` — FastAPI `description`: *"Legal practice sibling of the Evidence Platform. **Not a second evidence store.**"* This is enforced, not aspirational: there is no upload/OCR/ingest pipeline for case evidence anywhere in this repo. Evidence lives in a separate "Agno Evidence Platform" service reached over HTTP (`api/legal_workspace/services/agno_client.py`); Legal-Workspace only imports pre-approved, already-reviewed **identity/locator references** to that evidence (`LegalSourcePackage`), never bytes. The only real file-upload routes in this repo handle *owner-produced* PDFs (redaction, Bates stamping) and are explicitly marked "Not Agno evidence."
