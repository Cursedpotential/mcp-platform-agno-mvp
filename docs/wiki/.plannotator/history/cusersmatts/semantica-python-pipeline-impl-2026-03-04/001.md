# Semantica Python Pipeline Implementation Plan

## Overview

**Goal:** Replace Graphiti-based memory service with pure Semantica pipeline for single-case forensic analysis platform.

**Architecture:** 5-Tier (DuckDB + LanceDB + Neo4j/Semantica + PostgreSQL + MySQL)

**Key Change:** Single Neo4j database (`evidence_graph`) replaces dual-database setup (temporal_memory + semantic_facts).

## Phase 1: Foundation (Current Session)

### 1. Create `semantica_pipeline.py` - Core Processing Pipeline

**Location:** `python-tools/semantica_pipeline.py`

**Features:**
- NERExtractor (entity extraction from messages)
- RelationExtractor (relationship discovery)
- GraphBuilder(enable_temporal=True) (temporal knowledge graph)
- ConflictDetector (contradiction detection)
- SourceTracker (credibility weighting)
- EmbeddingGenerator (768-dim vectors for LanceDB)

**Pipeline Stages:**
```python
class SemanticaPipeline:
    async def ingest_message(self, message: IngestMessageRequest) -> IngestResult:
        # Stage 1: Entity Extraction
        entities = self.ner_extractor.extract(message.content)
        
        # Stage 2: Relation Extraction
        relations = self.relation_extractor.extract(message.content, entities)
        
        # Stage 3: Build Temporal Knowledge Graph
        kg = self.graph_builder.build(entities, relations, timestamp=message.timestamp)
        
        # Stage 4: Detect Conflicts
        conflicts = self.conflict_detector.detect_conflicts(kg)
        
        # Stage 5: Record Provenance (W3C PROV-O)
        provenance = self.record_provenance(entities, message.source_hash)
        
        # Stage 6: Generate Embeddings (for LanceDB)
        embeddings = self.embedding_generator.generate(message.content)
        
        return IngestResult(entities, relations, conflicts, provenance, embeddings)
```

```python
from semantica import AgentContext, ContextGraph, VectorStore
from semantica.semantic_extract import NERExtractor
from semantica.kg import GraphBuilder
from semantica.conflicts import ConflictDetector, SourceTracker
from semantica.embeddings import EmbeddingGenerator

# Single Neo4j database
NEO4J_DATABASE = os.getenv("NEO4J_DATABASE", "evidence_graph")

# Semantica context (handles everything)
semantica_context = AgentContext(
    vector_store=VectorStore(backend="neo4j", database=NEO4J_DATABASE),
    knowledge_graph=ContextGraph(enable_temporal=True),
    decision_tracking=True,
    provenance_tracking=True

```
