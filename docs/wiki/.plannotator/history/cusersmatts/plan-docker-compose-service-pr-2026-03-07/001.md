
# Plan: Docker Compose Service Profiles with Interactive Startup

## Problem
1. Python memory service, Semantica worker, Cosmo router, and Node API have Dockerfiles but NO docker-compose entries
2. Services 2-3 (Python) are falsely labeled "optional" — they're REQUIRED for Tier 3
3. Starting the platform requires 3-4 manual commands instead of one
4. No interactive prompt to choose what to start

## Solution: Docker Compose Profiles

Docker Compose `profiles` let you group services. Running `docker compose up` only starts services with NO profile (core). Running `docker compose --profile dev up` starts core + dev services. We'll also create a startup script that prompts you.

## Step 2: Create Interactive Startup Script

File: `scripts/start.sh` (and `scripts/start.ps1` for Windows)

The script will:
1. Always start core services (neo4j, postgres, mysql, redis, memory-service)
2. Prompt: "Start Semantica enrichment worker? (y/N)"
3. Prompt: "Start Cosmo federation router? (y/N)"
4. Prompt: "Start full API in Docker? (y/N) — or run 'pnpm dev' locally"
5. Prompt: "Start dev tools (Playwright, CLI bridge)? (y/N)"
6. Build the `docker compose --profile X --profile Y up -d` command
7. Show status summary with health checks
