# Cognitive Synthesis System — Design Document

**Date:** 2026-03-14
**Status:** DRAFT — Awaiting user review
**Author:** brainstorm@opencode

---

## Problem Statement

The user's cognitive process for forensic/narrative biographical writing involves a sophisticated multi-domain synthesis spanning 8 core domains, 10 frameworks, and 7 cognitive process patterns. This process is currently intuitive and unpredictable. The goal is to make it systematic, repeatable, and tool-supported by building a comprehensive skill/agent/prompt system.

## Findings by Domain

### 1. Forensic Analysis & Evidence Integration

**Key Tools Discovered:**
- **oletools** (3.3k stars) — MS Office document forensics, metadata extraction, OLE2 parsing
- **Docling** (IBM/LF) — Multi-format document parsing (PDF, DOCX, PPTX, HTML), OCR, table detection, reading order preservation
- **pdfplumber** — Precise PDF text/table extraction with metadata preservation
- **spaCy** — Industry-standard NLP for NER, relationship extraction, dependency parsing
- **PACER** — Federal court records API (becoming free in 2025)

**Critical Gap:** No off-the-shelf behavioral pattern mapping tool for family law/custody cases. Custom development required.

**Recommended Stack:**
- Docling (already integrated) → structured extraction
- oletools → MS Office forensics
- spaCy + custom NER models → behavioral pattern extraction
- Custom MCL 722.23 Factor Mapper → legal-specific classification

```

- `cardiffnlp/twitter-roberta-base-sentiment-latest` (3.3M downloads)

Tier 4 (PostgreSQL): Unified evidence index with resilience indicators
```

### 5. Behavioral Psychology & Pattern Recognition

**Key Tools Discovered:**

**Production-Ready Behavioral Coding:**
- **BORIS** (AGPL-3.0) — Behavioral Observation Research Interactive Software; multi-observer behavioral coding with temporal pattern detection; inter-rater reliability (Cohen's kappa); video/audio annotation; exports CSV/JSON; standard tool in family law for behavioral documentation
- **ELAN** (GPL) — EUDICO Linguistic Annotator; temporal annotation of behavioral events with multi-tier hierarchical coding and controlled vocabularies
- **Taguette** (GPL) — Open-source document annotation and behavioral coding with CSV/JSON export

**NLP & Pattern Analysis:**
- **spaCy** (MIT) — NER, dependency parsing, sentiment analysis for psychological entity extraction
- **Transformers/HuggingFace** (Apache 2.0) — BERT-based emotion detection, psychological language classification, zero-shot classification for custom behavioral patterns
- **Flair** (MIT) — NER with custom model training for psychological entity extraction
- **NLTK** (Apache 2.0) — Discourse analysis, behavioral language pattern extraction
- **TextBlob** (MIT) — Sentiment analysis, subjectivity detection, psychological language markers

**Network & Relationship Analysis:**
- **NetworkX** (BSD) — Behavioral relationship mapping, control network visualization, temporal network analysis, centrality measures
- **Gephi** (AGPL) — Network visualization, temporal network analysis, community detection for control/manipulation pattern visualization
- **PyTorch Geometric** (MIT) — Graph neural networks for behavioral pattern learning
- **DGL/Deep Graph Library** (Apache 2.0) — Temporal graph analysis, behavioral pattern discovery

**Temporal Pattern Analysis:**
- **TSlearn** (BSD) — Time series clustering, behavioral sequence matching, pattern discovery, anomaly detection
- **Stumpy** (BSD) — Time series motif discovery, repeating behavioral patterns, anomaly detection
- **Pandas** (BSD) — Time series analysis, behavioral sequence analysis

**Research-Stage:**
- **Ethoflow** — Automated behavioral coding from video using pose estimation (research prototype)
- **THEME** (Magnus Magnusson) — T-pattern analysis for hidden temporal patterns in behavior

**Critical Gaps (Custom Development Required):**
1. **DARVO Detection Engine** — Deny, Attack, Reverse Victim/Offender pattern recognition using Transformers-based classifier
2. **Cognitive Dissonance Detection** — Semantic analysis combining spaCy + Transformers for attitude-behavior inconsistency
3. **Strategic Escalation Mapping** — Implement Glasl's 9-stage conflict escalation model, Pondy's conflict process model, Evan Stark's coercive control escalation as state machines in Neo4j
4. **Coercive Control Mapping** — Custom framework combining BORIS coding + Neo4j relationship mapping for isolation tactics, economic control, emotional abuse, threats/intimidation

**Recommended Integration:**
```
BORIS coding → DuckDB (Tier 1) → spaCy/Transformers NLP → LanceDB embeddings (Tier 2)
→ Neo4j behavioral graph via Semantica (Tier 3) → NetworkX/Gephi visualization
→ Custom DARVO/escalation detectors → PostgreSQL unified index (Tier 4)
```

**Legal/Forensic Considerations:**
- Chain of custody via Semantica + PROV-O provenance
- Deterministic, auditable analysis paths for admissibility
- Document all ML model training data and limitations
- Version all analysis code and parameters
- Human-in-the-loop for critical findings
- Daubert Standard compliance for scientific validity

## Recommended Architecture: Cognitive Synthesis System

### Layer 1: Evidence Ingestion & Forensics
```
Sources → Docling (parsing) → oletools (MS Office) → DuckDB (hashing/dedup)
```

### Layer 2: Entity Resolution & Linking
```
DuckDB → Splink (probabilistic linkage) → LanceDB (vector embeddings) → Neo4j (entity graph)
```

### Layer 3: Behavioral & Emotional Analysis
```
Text → spaCy NER → HuggingFace emotion models → EmoNet (valence-arousal)
→ Custom DARVO/coercive control detector → Neo4j (behavioral graph)
```

### Layer 4: Timeline & Narrative Construction
```
Neo4j temporal queries → Timesketch/Plaso (timeline synthesis)
→ Drama Engine / StoryAssembler (narrative planning)
→ Style transfer models (voice preservation)
→ Consistency checker
```

### Layer 5: Legal Factor Mapping (Custom)
```
Evidence + Behavioral patterns → MCL 722.23 Factor Mapper
→ Precedent linking → Factor scoring → Legal strategy output
```

### Layer 6: Federated Query & Review
```
WunderGraph Cosmo (federated schema across all tiers)
→ React + CopilotKit (HITL review dashboard)
→ Export to legal documents
```

## Agent System Design

### Proposed New Agents

#### 1. `@forensic-synthesis` — Multi-Domain Evidence Synthesis
- **Purpose:** Synthesize evidence across forensic, behavioral, emotional, and temporal domains
- **Model:** Opus 4.6 thinking max
- **Tools:** Docling, spaCy, Splink, Neo4j queries, Timesketch
- **Output:** Integrated evidence narrative with provenance chain

#### 2. `@narrative-architect` — Biographical Narrative Construction
- **Purpose:** Build coherent narratives from fragmented evidence while preserving voice
- **Model:** Opus 4.6 thinking max
- **Tools:** StoryAssembler patterns, style transfer, consistency checking
- **Output:** Chapter drafts with voice preservation metadata

#### 3. `@behavioral-mapper` — Pattern Recognition & Documentation
- **Purpose:** Detect and document behavioral patterns (DARVO, coercive control, escalation)
- **Model:** Sonnet 4.6 thinking max
- **Tools:** spaCy NER, custom pattern matchers, temporal analysis
- **Output:** Behavioral pattern reports with evidence citations

#### 4. `@emotional-arc` — Emotional Trajectory Analysis
- **Purpose:** Map emotional trajectories and resilience patterns across evidence
- **Model:** Sonnet 4.6 thinking max
- **Tools:** EmoNet, HuggingFace emotion models, engagement metrics
- **Output:** Emotional arc visualizations, resilience documentation

#### 5. `@gap-bridger` — Evidence Gap Analysis
- **Purpose:** Identify gaps in evidence chains and suggest bridging strategies
- **Model:** Sonnet 4.6
- **Tools:** Splink, Data-Diff, temporal analysis, Neo4j queries
- **Output:** Gap analysis reports with recommended evidence sources

#### 2. `narrative-voice-preservation`

### Proposed New Prompts

#### 1. `forensic-synthesis.md`
```
You are a forensic evidence synthesizer. Your role is to:
1. Integrate evidence across multiple domains (documentary, behavioral, emotional, temporal)
2. Maintain chain of custody and provenance for every claim
3. Identify patterns, contradictions, and gaps
4. Produce structured synthesis reports with evidence citations

Always:
- Cite source documents with timestamps
- Flag confidence levels (high/medium/low)
- Note gaps and missing evidence
- Preserve emotional weight without editorializing
```

#### 2. `narrative-architect.md`
```
You are a biographical narrative architect. Your role is to:
1. Transform fragmented evidence into coherent narrative chapters
2. Preserve the subject's authentic voice and emotional truth
3. Maintain temporal consistency across the full narrative
4. Balance forensic accuracy with compelling storytelling

Voice Preservation Protocol:
- Extract voice patterns from primary source documents
- Maintain consistent tone, vocabulary, and sentence structure
- Flag when voice is reconstructed vs. directly quoted
- Preserve emotional weight of original language
```

#### 3. `behavioral-pattern-analyzer.md`
```
You are a behavioral pattern analyst specializing in family law contexts. Your role is to:
1. Detect DARVO patterns (Deny, Attack, Reverse Victim and Offender)
2. Identify coercive control indicators
3. Map strategic escalation patterns
4. Document gaslighting and manipulation tactics

Output Format:
- Pattern type with confidence level
- Supporting evidence with timestamps
- Temporal frequency analysis
- Impact assessment on affected parties
```

#### 4. `gap-bridger.md`
```
You are an evidence gap analyst. Your role is to:
1. Identify gaps in evidence chains
2. Assess the significance of each gap
3. Suggest bridging strategies (inference, corroboration, additional sources)
4. Evaluate the strength of existing evidence to support inferences

Gap Classification:
- Critical: Gap that undermines a key claim
- Significant: Gap that weakens but doesn't invalidate
- Minor: Gap that can be reasonably inferred
- Cosmetic: Gap that affects presentation but not substance
```

## Recommendation

Build a **layered cognitive synthesis system** that combines:

1. **Existing stack tools** (Docling, Neo4j, Semantica, DuckDB, LanceDB, PostgreSQL) for infrastructure
2. **Best-of-breed open source** (spaCy, Splink, HuggingFace models, oletools, Timesketch) for core capabilities
3. **Custom agents and skills** for domain-specific synthesis (forensic, narrative, behavioral, emotional, legal)
4. **Off-the-shelf models as foundations** (DARVO regressor, abuse detector, hate-alert BERT, MER framework, MentalManip dataset) for behavioral pattern detection — fine-tuned for custody-specific use cases
5. **Minimal custom components** only where no tool exists (voice fingerprinting, cross-chapter coherence)

The system should follow the **DIAL Stack's tiered architecture** with evidence flowing through:
- Tier 1 (DuckDB): Hashing, dedup, master clock
- Tier 2 (LanceDB): Multimodal embeddings
- Tier 3 (Neo4j): Temporal knowledge graph with behavioral/emotional nodes
- Tier 4 (PostgreSQL): Unified evidence index with legal factor mappings
- WunderGraph Cosmo: Federated query layer
- React + CopilotKit: HITL review dashboard
