## Problem Statement

The user's cognitive process for forensic/narrative biographical writing involves a sophisticated multi-domain synthesis spanning 8 core domains, 10 frameworks, and 7 cognitive process patterns (extracted from Gemini thought bubble analysis). This process is currently intuitive and unpredictable. The goal is to make it systematic, repeatable, and tool-supported by building a comprehensive skill/agent/prompt system **on top of the existing dial-stack infrastructure**.

---

## Key Insight: Build on Existing Infrastructure

The dial-stack already has the full infrastructure. The cognitive synthesis system should:

1. **Use existing Semantica pipeline** as the core NLP/processing engine (11 MCP tools, 7-stage pipeline, PROV-O provenance)
2. **Add new behavioral detection models** (Red Flag, DARVO, MENTALMAC) as Py MCP Server tools
3. **Create secondary Semantica instance** for agent-only analysis (separate from evidence database)
4. **Build new agents** that orchestrate existing infrastructure via DIAL
5. **Custom ML models = Sprint 2** — after basic skill/agent framework is working

## Development Priorities (User Feedback)

### Priority 1: Red Flag Detector
**IshuTak/red-flag-detector** — Fine-tuned DistilRoBERTa model
- 95% accuracy for critical patterns, 85-90% manipulation, 90% positive
- Detects: controlling behavior, manipulation, gaslighting, emotional abuse, threats, isolation
- Web interface, conversation pattern detection, severity assessment
- **Action:** Integrate as Py MCP Server tool

### Priority 2: National Alert System (NAS)
**vaishnavinalawade/nas** — Offline-first, privacy-centric AI pipeline
- Detects: psychological abuse, coercive control, gaslighting, workplace harassment, digital stalking
- Outputs: behavioral risk indicators, sentiment signals, composite risk scores (0-100), SMS/Email alerts, FIR-ready summaries
- Python-based, deterministic NLP engine
- **Action:** Study architecture, integrate detection patterns as Py MCP Server tools

### Priority 3: Coercive Control Text Mining (Karystianis et al., 2024)
- Rule-based text mining identifying **48 coercive control behaviors**
- 406,196 DFV police reports (NSW, 2009-2020)
- 54.6% had at least one coercive control behavior
- Most common: verbal abuse (38.9%), property damage (30.0%)
- Least common: financial (3.2%), social abuse (0.4%)
- **Action:** Use 48-behavior taxonomy to configure detection tools

### Priority 4: MENTALMAC Dataset & Framework
**arXiv 2025** — Multi-task anti-curriculum distillation for mental manipulation detection
- EvoSA: annotation-free data augmentation via evolutionary operations + speech act theory
- ReaMent dataset: 5,000 real-world dialogue samples
- 25.9% F1 improvement, 8.1% accuracy improvement over GPT-4
- Outperforms Claude-3.5-Sonnet
- **Action:** Use ReaMent dataset for fine-tuning, study EvoSA for data augmentation

## Secondary Semantica Database (Agent-Only Analysis)

**Purpose:** A separate Semantica instance for agent analysis, distinct from the primary evidence database.

**Rationale:**
- Agents need to run exploratory analysis without touching evidence
- Behavioral pattern detection may generate intermediate results
- Narrative construction needs a workspace for drafts and revisions
- Temporal consistency checking requires cross-referencing without modifying evidence

**Architecture:**
```
Primary Semantica (Evidence)          Secondary Semantica (Agent Workspace)
├── Neo4j: evidence_graph             ├── Neo4j: analysis_graph
├── LanceDB: evidence_vectors         ├── LanceDB: analysis_vectors
├── DuckDB: evidence_worm             ├── DuckDB: analysis_workspace
└── PostgreSQL: evidence_index        └── PostgreSQL: analysis_index
```

**Integration:**
- Secondary instance runs as additional Py MCP Server tools
- Agents write to secondary DB, read from both
- Promotion workflow: validated analysis results → primary evidence DB
- WORM rules apply to primary only; secondary is read-write

## Agent System Design

### New Agents (Built on DIAL Orchestration)

#### 1. `@forensic-synthesis` — Multi-Domain Evidence Synthesis
- **Purpose:** Synthesize evidence across forensic, behavioral, emotional, and temporal domains
- **Model:** Opus 4.6 thinking max
- **Tools:** Existing Semantica tools + new behavioral detectors + WunderGraph queries
- **Output:** Integrated evidence narrative with provenance chain
- **Database:** Reads primary evidence, writes to secondary Semantica

#### 2. `@narrative-architect` — Biographical Narrative Construction
- **Purpose:** Build coherent narratives from fragmented evidence while preserving voice
- **Model:** Opus 4.6 thinking max
- **Tools:** Semantica temporal facts + faststylometry + style transfer + consistency checking
- **Output:** Chapter drafts with voice preservation metadata
- **Database:** Reads both primary and secondary Semantica

#### 3. `@behavioral-mapper` — Pattern Recognition & Documentation
- **Purpose:** Detect and document behavioral patterns (DARVO, coercive control, escalation)
- **Model:** Sonnet 4.6 thinking max
- **Tools:** Red Flag Detector + DARVO regressor + NAS risk scorer + Coercive Control Analyzer
- **Output:** Behavioral pattern reports with evidence citations
- **Database:** Writes to secondary Semantica, reads primary for correlation

#### 4. `@emotional-arc` — Emotional Trajectory Analysis
- **Purpose:** Map emotional trajectories and resilience patterns across evidence
- **Model:** Sonnet 4.6 thinking max
- **Tools:** HuggingFace emotion models + Semantica embeddings + temporal analysis
- **Output:** Emotional arc visualizations, resilience documentation
- **Database:** Reads primary, writes analysis to secondary

#### 5. `@gap-bridger` — Evidence Gap Analysis
- **Purpose:** Identify gaps in evidence chains and suggest bridging strategies
- **Model:** Sonnet 4.6
- **Tools:** Splink + Data-Diff + Semantica temporal analysis + Neo4j queries
- **Output:** Gap analysis reports with recommended evidence sources
- **Database:** Reads both primary and secondary

### New Skills

#### 1. `behavioral-pattern-detection`
- DARVO pattern recognition using `SamanthaStorm/tether-darvo-regressor-v1`
- Red Flag detection using `IshuTak/red-flag-detector`
- NAS risk scoring using `vaishnavinalawade/nas`
- Coercive control analysis using Karystianis 48-behavior taxonomy
- MENTALMAC integration for mental manipulation detection

#### 2. `narrative-voice-preservation`
- Voice fingerprinting using faststylometry (Burrows' Delta)
- Resemblyzer for audio voice embeddings (if audio evidence exists)
- Style transfer model selection and application
- Consistency checking across chapters via Semantica temporal facts

#### 3. `emotional-resilience-mapping`
- Valence-arousal trajectory construction via HuggingFace emotion models
- Engagement/coping capacity assessment
- "Montage of survival" narrative construction
- Emotional arc tracking via secondary Semantica

#### 4. `temporal-synthesis`
- Timeline construction from multi-source evidence via Semantica
- Causal chain analysis via Neo4j graph traversals
- Contradiction detection across time periods via Semantica conflict detection
- Cross-referencing primary and secondary databases

#### 5. `legal-factor-integration`
- MCL 722.23 factor mapping (already exists — enhance)
- Evidence-to-factor classification using behavioral pattern data
- Precedent linking and factor scoring
- Integration with WunderGraph for deterministic queries

### New Prompts

#### 1. `forensic-synthesis.md`
```
You are a forensic evidence synthesizer operating within the AI DIAL stack.
Your role is to:
1. Integrate evidence across multiple domains (documentary, behavioral, emotional, temporal)
2. Use Semantica tools for entity extraction, temporal facts, and conflict detection
3. Use behavioral detection tools (Red Flag, DARVO, NAS) for pattern analysis
4. Maintain chain of custody and PROV-O provenance for every claim
5. Write analysis results to the secondary Semantica database

Always:
- Use semantica_track_provenance for every analysis step
- Cite source documents with timestamps from DuckDB master clock
- Flag confidence levels (high/medium/low)
- Note gaps and missing evidence
- Preserve emotional weight without editorializing
```

#### 2. `narrative-architect.md`
```
You are a biographical narrative architect operating within the AI DIAL stack.
Your role is to:
1. Query Semantica temporal facts for chronological ordering
2. Use faststylometry for voice fingerprinting from source documents
3. Transform fragmented evidence into coherent narrative chapters
4. Maintain temporal consistency via Neo4j temporal graph queries
5. Preserve the subject's authentic voice and emotional truth

Voice Preservation Protocol:
- Use faststylometry Burrows' Delta for authorial voice analysis
- Extract voice patterns from primary source documents
- Maintain consistent tone, vocabulary, and sentence structure
- Flag when voice is reconstructed vs. directly quoted
- Store narrative drafts in secondary Semantica database
```

#### 3. `behavioral-pattern-analyzer.md`
```
You are a behavioral pattern analyst specializing in family law contexts.
Your role is to:
1. Run Red Flag Detector on text excerpts for manipulation patterns
2. Run DARVO regressor for Deny, Attack, Reverse Victim/Offender patterns
3. Run NAS risk scorer for composite behavioral risk assessment
4. Apply Karystianis 48-behavior coercive control taxonomy
5. Map patterns to MCL 722.23 best interest factors

Output Format:
- Pattern type with confidence level from model inference
- Supporting evidence with timestamps from DuckDB master clock
- Temporal frequency analysis via Semantica temporal facts
- MCL factor mapping from existing factor mapper
- Risk score (0-100) from NAS composite scoring
```

#### 4. `gap-bridger.md`
```
You are an evidence gap analyst operating within the AI DIAL stack.
Your role is to:
1. Query WunderGraph Cosmo for cross-tier evidence coverage
2. Use Semantica conflict detection to identify contradictions
3. Use Splink for entity resolution across fragmented sources
4. Assess the significance of each gap
5. Suggest bridging strategies

Gap Classification:
- Critical: Gap that undermines a key claim
- Significant: Gap that weakens but doesn't invalidate
- Minor: Gap that can be reasonably inferred
- Cosmetic: Gap that affects presentation but not substance
```

## Recommendation

Build a **layered cognitive synthesis system** that:

1. **Leverages existing dial-stack infrastructure** (Semantica, DIAL Core, WunderGraph, 4-tier storage, Keycloak auth)
2. **Wraps off-the-shelf behavioral detection models** as Py MCP Server tools (Red Flag, DARVO, NAS, Abuse Detector)
3. **Creates secondary Semantica database** for agent workspace (separate from evidence)
4. **Builds 5 new agents** that orchestrate existing + new tools via DIAL
5. **Creates 5 new skills** documenting the behavioral detection, voice preservation, emotional mapping, temporal synthesis, and legal factor integration workflows
6. **Defers custom ML model training to Sprint 2** — get the framework working first with off-the-shelf models
7. **Uses existing MCL Factor Mapper** — don't rebuild what already exists
8. **Uses existing voice fingerprinting tools** (faststylometry, Resemblyzer) — don't build custom

The system follows the dial-stack's tiered architecture with evidence flowing through the existing 4-tier storage, behavioral analysis stored in the secondary Semantica workspace, and WunderGraph Cosmo providing deterministic federated queries for legal defensibility.
