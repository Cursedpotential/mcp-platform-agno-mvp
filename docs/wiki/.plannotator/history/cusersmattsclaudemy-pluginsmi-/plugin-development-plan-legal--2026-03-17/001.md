## Item 3: Strategy Files Architecture

### User Specification

- Strategy files will be sourced from OneDrive case Bible
- Use symlink approach - create files in plugin, symlink to case Bible
- User's case Bible is the source of truth

### Proposed Structure

**Source (OneDrive):**
```
OneDrive/CaseBible/
├── strategies/
│   ├── evidence-exclusion.md      # MRE 403 rules, what to exclude
│   ├── citation-standards.md       # MCL/MCR citation formats
│   ├── terminology-mappings.md    # Vocabulary hook definitions
│   └── factor-mappings.md         # MCL 722.23 factor-to-evidence
```

**Plugin (symlinked):**
```
mi-legal-resources/
├── strategies/  → symlink to OneDrive/CaseBible/strategies/
```
