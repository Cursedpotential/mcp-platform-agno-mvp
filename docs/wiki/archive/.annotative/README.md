# Annotative Storage

This folder contains your project's annotations and custom tags.

## Version Control

**Recommended:** Include this folder in version control to share annotations with your team.

```bash
git add .annotative/
git commit -m "Add annotations"
```

**Private annotations:** Add `.annotative/` to your project's `.gitignore` file.

## Files

- `annotations.json` - All annotations in this project
- `customTags.json` - User-defined tag definitions
