# Agent Adapter Memory

> _Byline: Codex · GPT-5 · 2026-08-27._

- Agents reason over governed interfaces; they never become evidence, custody, schema, or promotion
  authority.
- The current Agno layer is an adapter under replacement. Preserve platform-owned contracts and
  neutral APIs so orchestration can migrate without changing evidence semantics.
- Knowledge-horizon enforcement happens as a pre-filter in each store before retrieval.
- Extraction forms no beliefs. Belief state belongs to the governed agent/walk layer.
- Multi-agent deliberation may use AG2 or another coordinator, while Temporal continues to own
  durability and workflow state.
