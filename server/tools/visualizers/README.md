# Visualizers

> _Byline: Codex · GPT-5 · 2026-08-14_

Rendered, cross-domain visual outputs registered through `server.tools.registry`.

- `geo_map.py` — `viz.geo_map`, a self-contained Leaflet map from point records,
  CSV, or JSON.
- `geo_map_schema.json` and `geo_map_template.csv` — portable input contract.
- `assets/` — vendored Leaflet 1.9.4 runtime used for offline HTML output.
