# Bootstrap baselines

## `schema_baseline_20260830.sql`  ← CURRENT

Snapshot of the live `platform` database taken 2026-08-30, generated by
`scripts/generate_schema_baseline.py` using PostgreSQL's own DDL serializers
(`pg_get_constraintdef`, `pg_get_indexdef`, `pg_get_viewdef`,
`pg_get_functiondef`) — no hand-written DDL.

**Builds the entire database in ~11 seconds from this one file.**
315 tables · 37 views · 32 enums · 6 domains · composite types · 0 triggers.

Verified by building a throwaway database from it and diffing against live:
table count, view count, index count and FK count all match exactly.

### Why this replaced the old baseline

`schema_baseline.sql` was a `pg_dump` from **2026-08-10**. It went stale and
was never re-taken. Two consequences bit us repeatedly:

1. **Deleted tables kept coming back.** Dropping a dead table from the live
   database did nothing, because the next rebuild replayed the August photo
   and recreated it. On 2026-08-30 five superseded tables were removed and
   resurrected the same evening. (D-113)
2. **The numbered migrations alone cannot build the database.** `evidence.source`,
   `working.normalized_record` and `working.message` are created by NO numbered
   migration — only by the baseline dump. Every from-scratch build attempt
   failed on this, repeatedly, for two days. (D-108)

Re-baselining fixes both. Deletion is now permanent, and the build is one file
instead of `baseline + 50 migrations × 3 passes`.

### Rules

- **Migrations `0001`–`0055` are HISTORY, not build steps.** Do not replay them
  against a fresh database. The next new migration is `0056`.
- **To make a schema deletion permanent, regenerate this file.** Dropping from
  the live database alone is temporary — see reason 1 above.
- **Re-baseline whenever the schema is "complete pending minor iterations."**
  Run `scripts/generate_schema_baseline.py`, verify against a throwaway
  database, commit. This is routine, not exceptional.
- **No immutability guards are included.** All 131 guard triggers in the old
  chain protected `context`/`working` (layers under construction), lookup
  registries, or a finished consolidation. **Zero protected `evidence.*`.**
  See `docs/GUARD-TRIGGER-DISPOSITION.md`. (D-110)
